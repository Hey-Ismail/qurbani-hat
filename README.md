# Qurbani Hat 🐄

Qurbani Hat is a livestock booking platform where users can browse available animals, view detailed information, and book animals for Qurbani. The project includes user authentication, protected routes, and a responsive user interface.

## Live Site

🔗 Live Link: [Add Your Live URL Here]

## Features

* User Registration and Login
* Google Authentication
* Protected Booking Page
* Browse All Available Animals
* View Animal Details
* Sort Animals by Price
* Booking Form with Success Toast
* Responsive Design
* Custom Loading and 404 Pages
